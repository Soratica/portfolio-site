Stations

The apps running on the panel. Each one is built, shipped and operated on the platform above.

  • Gym Hero

    An RPG-themed workout tracker. Logging a real workout levels up a character, with every submission handled as one all-or-nothing transaction.

    Next.js · TypeScript · MongoDB replica set · auto-deployed on commit

    Station notes →

  • Music Shuffler

    Pulls a random track from a curated YouTube playlist and shows it off with a shuffle animation.

    Flask · gunicorn · YouTube Data API · API key in a Kubernetes Secret · auto-deployed on commit

    Station notes →

  • Job Planner

    Compares job offers and relocation costs: salary to take-home, rent planning, neighborhood and commute comparisons.

    Vanilla JS front end · small Express sync API · two deployments, one namespace
