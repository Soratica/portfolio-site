What it does

Drivers who modify their own cars log two things: what they changed, and how the car ran at the track. Built Diff keeps both on the same vehicle and draws them on one timeline. Each session is compared with the last visit to that track and with the driver's best there, because a session can beat last time and still be well off a personal best.

Lap times go in the way people write them, 1:32.4 on a road course or 92.4 at an autocross, and are stored as seconds so best laps and deltas are plain arithmetic.

Stack

Next.js 16 with the App Router and TypeScript, MongoDB Atlas through Mongoose, Zod validation on every request body, Clerk for sign-in, and Cloudflare R2 for photos, uploaded straight from the browser with presigned URLs.

Design choices

Auth lives behind one function that every route and Server Action calls. Owner-only lookups return 404 rather than 403, so the API never confirms that someone else's vehicle exists. Best lap is derived on write and can't be set by a client. Public share links are permanent, because a link that changes is a broken link.
