Gym Hero

An RPG-themed workout tracker. Logging a real workout levels up a character across four stats, with quests, loot, streaks and personal records framed as boss battles.

  • Live demo
  • Source

How it works

Every logged set feeds XP into the stat its exercise trains: a barbell squat trains Strength, a run trains Endurance, and so on. Stats level independently on an escalating XP curve, and the overall character level rewards balanced training over maxing one stat. A new personal record triggers a boss-battle moment. Daily and weekly quests and a workout streak earn bonus XP and random loot.

Stack

Next.js (App Router) with TypeScript end to end, MongoDB with Mongoose, and Auth.js for real account authentication. The whole workout submission (XP, level-ups, PR detection, streaks, quest progress and loot rolls) runs through one transactional service, so a submission either fully lands or doesn't land at all.

Why the database is a replica set

MongoDB only supports multi-document transactions on a replica set, so the in-cluster database runs as a single-member replica set with a keyfile from a Kubernetes Secret. The member's advertised host is reconfigured to the Service name, because pod hostnames don't resolve inside the cluster.
