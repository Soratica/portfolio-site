How it works

The figures are linked: pay feeds the rent budget, the rent budget feeds the full monthly budget, and the job location feeds the commute comparison. Change one input and everything that depends on it updates. All of the maths runs in the browser.

Stack

A single-file vanilla HTML, CSS and JavaScript front end with no framework and no build step, served by nginx. A small Express API alongside it lets the same plan sync between a phone and a desktop with a short PIN, with rate limiting on the PIN endpoints.

Running it

Two Deployments share the job-planner namespace: the static front end and the API. They're separate so each can be rebuilt and restarted on its own.
