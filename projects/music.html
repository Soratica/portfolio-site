Music Shuffler

Live: No reading · — ready · last rollout —

A small Flask app that pulls a random track from a curated YouTube playlist and shows it with a shuffle animation: a quick way to find something new to listen to.

Stack

Flask with the app-factory pattern, server-rendered Jinja templates, and Google's YouTube Data API v3 for playlist data.

Running it

One gunicorn-served pod. The YouTube API key, playlist ID and Flask secret key are held in a Kubernetes Secret and injected as environment variables, so none of them live in the image or the repo.

How it's deployed and operated

  1. Commitpushed to GitHub
  2. Watchersystemd timer fetches, fast-forward only
  3. Builddocker build in LXC 100
  4. Shipimage streamed into LXC 102, ctr import
  5. Roll outrollout restart + rollout status

Auto-deployed: a commit to master is live within about five minutes, and shows up in the panel's register.
